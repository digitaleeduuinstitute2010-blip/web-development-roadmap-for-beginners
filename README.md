# Web Development Roadmap for Beginners

A simple, step-by-step path for anyone who wants to learn web development from scratch. It lists what to learn, in what order, and what to build at each stage.

If you've been jumping between tutorials without knowing what comes next, start here.

## Who this is for

- Students and graduates who want a career in web development
- Career switchers starting from zero
- Designers who want to understand code
- Small business owners who want to build their own site

## How to use this roadmap

Go in order. Don't move to the next stage until you've built the small project listed under the current one. Reading is not the same as learning. Building is.

## Stage 1: HTML and CSS (3 to 4 weeks)

**Learn**
- HTML structure: headings, links, images, forms, tables
- CSS basics: colours, fonts, spacing, the box model
- Flexbox and Grid for layouts
- Responsive design so pages work on phones

**Build**
- A personal profile page
- A responsive landing page for an imaginary business

**Free resources**
- [MDN Web Docs](https://developer.mozilla.org/)
- [freeCodeCamp Responsive Web Design](https://www.freecodecamp.org/)

## Stage 2: JavaScript (6 to 8 weeks)

**Learn**
- Variables, functions, loops and conditions
- Arrays and objects
- Working with the DOM
- Events, forms and basic validation
- Fetching data from an API

**Build**
- A to-do list app
- A simple calculator
- A weather app using a public API

**Free resources**
- [javascript.info](https://javascript.info/)
- [MDN JavaScript Guide](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide)

## Stage 3: Git and GitHub (1 week)

**Learn**
- `git init`, `add`, `commit`, `push`, `pull`
- Branches and merging
- Writing a clear README

**Do**
- Put every project from Stages 1 and 2 on GitHub
- Publish one project with GitHub Pages

## Stage 4: Pick a direction

| Path | Good for | What to learn |
|------|----------|---------------|
| Frontend | People who like building interfaces | React, component design, state management |
| WordPress | Freelancers and small business sites | Themes, plugins, WooCommerce, site speed |
| Backend | People who like logic and data | PHP or Node.js, SQL, REST APIs |

You don't need to master all three. Pick one and go deep.

## Stage 5: Build a portfolio

Employers look at what you've built. Aim for 4 to 6 projects:

- [ ] A responsive business website
- [ ] A JavaScript app that uses an API
- [ ] A small React project
- [ ] A WordPress or WooCommerce site
- [ ] One project that solves a real problem you noticed

For each project, write a README that explains what it does, how to run it and what you learned.

## Common beginner mistakes

- Watching tutorials without building anything
- Learning a framework before JavaScript basics
- Copying code without understanding it
- Never uploading projects to GitHub
- Waiting until you feel "ready" to apply for jobs

## Project ideas

- Recipe finder
- Expense tracker
- Quiz app
- Blog with a simple admin panel
- Online store for a local shop
